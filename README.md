# Conversa AI: Netlify investor demo (pre-built)

Static build of the Conversa AI demo. The product runs entirely in the browser (no backend needed).

**Deploy:** in Netlify choose *Add new site → Import from Git*, select this repo, leave the build command empty. The publish directory is `.` (set in `netlify.toml`).

Source code lives in the main Conversa-AI repository.
